# Inspector_Website_004

منصة ويب عربية ذات اتجاه من اليمين إلى اليسار (RTL) لمساعدة مفتش التكوين والتعليم المهنيين في الجزائر في إدارة وتنفيذ الزيارات التفتيشية الميدانية بحرية وشفافية وحماية الحقيقة التاريخية.

---

## 🚀 المميزات الرئيسية

1. **إدارة المراجع مستقلة التغيير (Inspection References Library):**
   - دعم المراجع المشتركة العامة والمراجع الخاصة بالمفتشين.
   - بنية هرمية مرنة (`BRANCH`, `SPECIFICATION`, `CHECKLIST_ITEM`).
   - اقتراح تعميم المراجع الخاصة وحفظ لقطات غير قابلة للتغيير عند التقديم.

2. **الزيارات وتجميد الملاحظات التاريخية (Frozen Visit Snapshots):**
   - عند إنشاء أي زيارة، يُجمد المرجع المصدر فوراً في لقطة تاريخية (`frozen_snapshot`).
   - تعديل أو حذف المرجع الأصلي لا يؤثر مطلقاً على الزيارات القائمة.

3. **تحديد النطاق الاختياري (Selective Scope):**
   - يبدأ المفتش بنطاق فارغ يختار منه العناصر المراد تفتيشها.
   - التمييز بين العناصر المختارة فعلياً للتفتيش (`SELECTED`) والعناصر الأب المعروضة للسياق الهيكلي فقط (`CONTEXT`).
   - حساب نسبة الإنجاز والتقدم يعتمد حصراً على البنود النشطة المختارة للتفتيش.

4. **الاستبعاد والاسترجاع المرن (Soft Exclusion & Restoration):**
   - إمكانية استبعاد أي عنصر من نطاق الزيارة دون حذفه نهائياً.
   - عند استرجاع العنصر المستبعد، يسترجع مع كلاً من النتيجة والملاحظات التفتيشية المدونة سابقاً دون ضياع.

5. **المحتوى المحلي والتأليف الميداني (Local Visit Authoring):**
   - يستطيع المفتش إضافة فروع وبنود خاصة بالزيارة الميدانية وتكون معلمة بـ (`LOCAL`).

6. **أدلة التفتيش القياسية الاختيارية (Optional Guides):**
   - إمكانية إنشاء أدلة وتطبيقها لاقتراح بنود التفتيش دون فرض قفل أو إلزام.
   - تطبيق الدليل خاصية محصنة من التكرار (`Idempotent`).

7. **التكليفات الرسمية والقيود المزدوجة (Required Assignments & Constraints):**
   - التكليفات الصادرة من الإدارة تتمتع بخاصية الإصدار الذري (`Atomic Issue`).
   - تطبيق قيود مستقلة: قفل النطاق (`scope_locked`) والإلزام بالإكمال (`completion_required`).
   - عند إلغاء التكليف يلزم تسجيل السبب رسمياً للحفاظ على السجل التدقيقي (`Audit Trail`).

8. **إكمال الزيارة وتصدير البيانات (Completion & Deterministic Export):**
   - الزيارة المكتملة حقيقة تاريخية محمية يمنع تعديلها أو حذفها.
   - تصدير الزيارات إلى صيغة `JSON` منظمة ومحددة الإصدار (`Versioned`).

## 🛠️ المتطلبات التشغيلية والتثبيت

### 1. الاستنساخ والبيئة الافتراضية
```bash
git clone https://github.com/scientifica007/Inspector_Website_004.git
cd Inspector_Website_004

python3 -m venv venv
source venv/bin/activate  # أو venv\Scripts\activate على Windows
```

### 2. تثبيت الحزم والمكتبات
```bash
pip install -r requirements.txt
```

### 3. تطبيق الهجرات (Migrations)
```bash
python manage.py migrate
```

### 4. تحضير البيانات النموذجية (Demo Seed Data)
```bash
python manage.py seed_demo_data
```
**بيانات الدخول النموذجية:**
- **حساب المدير (ADMIN):**
  - اسم المستخدم: `admin`
  - كلمة المرور: `admin123`
- **حساب المفتش (INSPECTOR):**
  - اسم المستخدم: `inspector`
  - كلمة المرور: `inspector123`

### 5. تشغيل خادم التطوير
```bash
python manage.py runserver 0.0.0.0:8000
```

## 📱 التقييم والتجربة عبر الهاتف المحمول (Mobile LAN Testing)

لاختبار المنصة من هاتف محمول عبر الشبكة المحلية LAN:
1. حدد عنوان IP المحلي لجهاز الحاسوب (مثلاً: `192.168.1.50`).
2. اضبط متغير البيئة:
   ```bash
   export DJANGO_ALLOWED_HOSTS="localhost,127.0.0.1,192.168.1.50"
   ```
3. شغل السيرفر مستهدفاً جميع الواجهات:
   ```bash
   python manage.py runserver 0.0.0.0:8000
   ```
4. افتح المتصفح في الهاتف عبر: `http://192.168.1.50:8000`.
